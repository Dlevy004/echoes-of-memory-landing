# Echoes of Memory - Official Landing Page

This repository contains the source code for the landing page of **Echoes of Memory**, a first-person psychological horror experience.

The game itself was developed in **Unity** as a university thesis project, focusing heavily on atmospheric storytelling and environmental narrative depth.

## 🛠️ Tech Stack and Tools

- **React** + **Vite**
- **Tailwind CSS**

- Git, Github
- Figma

## 🌑 About the Design
The design philosophy of this landing page mirrors the game itself:
* **Minimalist & Dark:** Focusing on the psychological horror elements without overwhelming the user.
* **Atmospheric:** Utilizing dark color palettes, subtle animations, and environmental references from the game.
* **Responsive:** Fully optimized for both desktop and mobile viewing.

## 🎓 Background
*Echoes of Memory* is a university thesis project exploring the depths of environmental storytelling in the psychological horror genre. This website was created to showcase the game's narrative depth, visual style, and development journey.
